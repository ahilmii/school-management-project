<h1>School Management Project</h1>

<p>The goal of this project is to develop a REST-API web application using Java (version 25) Spring-Boot
framework (version 4.0.1) and Maven build tool (version 4.0.0). PostgreSQL database server
is used for data storage. </p>

<p>
<ul>
<li>Repository, Service and Controller layers designed and implemented carefully.</li>  
<li>Data returns handled with a proper DTO (Data Transfer Object).</li>
<li>New data insertions and manipulations creates a log line at standart output.</li>  
<li>All exceptions and errors handled carefully creating proper logs</li>
<li>End-points has been controlled via Postman. Application endpoints documented with Swagger.</li>
</ul>   
</p>
